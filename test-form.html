GovConnect - Halaman Pengujian Ekstensi

1. Uji Prefix Stripper & Jaro-Winkler

Menguji pembersihan prefix form_ dan inp_. Seharusnya dipetakan ke full_name.

2. Uji BM25 (Label Panjang)

Tidak ada Name/ID yang jelas. Ekstensi harus menggunakan BM25 untuk mengekstrak makna dari kalimat panjang dan menghasilkan skor ≥ 0.80 (dipetakan ke mothers_name).

3. Uji Observer Debounce (Burst Mutation)

Simulasi SPA (React/Angular) yang merender ulang class CSS dengan brutal. Fungsi maxWait (1500ms) harus memicu update agar tidak hang/silent failure.

4. Uji "Final Boss" (Shadow DOM)

Input berada di dalam Shadow Root (open). Ekstensi harus menembus batas Shadow DOM dan memetakan elemen ini ke first_name.

5. Uji Offscreen Document & SBERT (Semantic Fallback)

Label ini sangat implisit dan tidak masuk akal secara leksikal. Skor Jaro-Winkler & BM25 akan gagal (< 0.55), memicu Fallback Semantic (Offscreen.js) untuk mencari mothers_name.
